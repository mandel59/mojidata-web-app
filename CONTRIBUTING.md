# Contributing to Mojidata Web App

The source code of Mojidata Web App is available under the
[MIT license](LICENSE.md). By contributing, you agree that your contribution is
provided under the same license.

Bundled fonts, data and other third-party resources keep their own licenses;
see [LICENSE.md](LICENSE.md) and [download.txt](download.txt). If your change
adds or updates such a resource, state its source URL, version and license in
the pull request. Only submit material you have the right to submit.

Before opening a pull request, run `npm run lint` and `npm run build`, and
describe what the change does and how you checked it. For larger changes, open
an issue first.
